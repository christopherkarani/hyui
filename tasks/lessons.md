# Lessons

## 2026-02-25
- When the user asks to revert all changes, execute reset/clean immediately and verify `git status` is empty before proceeding with new work.
- Before large UI passes, confirm any external skill/reference URL is valid; if cloning fails, continue with the requested outcome using direct implementation and report the failure clearly.
- If the user asks for more creativity, increase concept boldness (visual narrative, motion, and hierarchy), not just token-level refinements.
- If the user provides a local skill pack path, install from that path directly and verify destination availability (`~/.claude/skills` and current runtime skills location).
- When the user asks to redo an earlier Three.js pass, replace the effect architecture end-to-end instead of incremental tweaks so the visual direction is clearly different.
- When the user gives explicit visual semantics (e.g., globe continents and country arcs), implement those literal motifs first before adding stylistic abstractions.
- For Three.js hero work, always verify luminance balance in a real screenshot and cap point-size/additive blending before sign-off to avoid white-out artifacts over key text.
